APPLY

2. In the project folder run:
   php artisan migrate
   php artisan optimize:clear

VEHICLE
- Direct entry list with Pending / Approved filter and View action.
- View opens /vehicle-entries/accounts/{creator_user_id}: all trips added by that user across every reference, Total Payment, Total Paid, Balance, central Credit / Debit and payment history.
- Only approved trip amounts enter the wallet. Credit means paid to the user; debit means returned payment. Calculations use integer paise.
- Vehicle tracking does not check or subtract stock; approved sales retain the existing stock calculation.
- Admin can approve, edit and manage wallet payments, but cannot create a vehicle entry. Staff creation follows assigned permissions and needs admin approval.
- The reference dropdown and server validation exclude the creator and admin. Reference is trip metadata; the wallet belongs to the user who added the trips.
- Search, pagination, approval and wallet payment refresh asynchronously with loading indicators.

PARTNER STATUS
- Admin can select multiple images, preview them, remove individual images and add more on edit.
- Up to 10 images per transaction, 5 MB per image. JPG, PNG and WebP are compressed to WebP in public/uploads/partners. PHP GD WebP support is required.
- All image paths are stored in partner_transactions.attachment_paths as one JSON array.
- The new 000004 migration preserves the existing single attachment, including archived transactions, and removes the old single-path column.
- Editing without selecting/removing images preserves the existing images. Only selected images are deleted after a successful update.
